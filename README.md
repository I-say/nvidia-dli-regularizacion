## 🚀 Cómo empezar

### **Opción A: Sin instalación (recomendado)**

1. Abre cualquier módulo con el botón **"Abrir en Colab"**
2. Ejecuta las celdas en orden (Shift + Enter)
3. Juega con el código, cambia valores, quiebra cosas — es la mejor forma de aprender

**Requisito:** Solo Gmail y conexión a internet.

### **Opción B: En tu máquina**

```bash
git clone https://github.com/I-say/nvidia-dli-regularizacion.git
cd nvidia-dli-regularizacion
jupyter notebook
```

**Requisitos:**
- Python 3.8+
- Jupyter Notebook o JupyterLab
- NumPy, Matplotlib (instrucciones en cada notebook)
